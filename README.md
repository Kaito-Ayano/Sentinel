# Sentinel — AI-assisted audit demo

**Deloitte Digital Camp 2026 · Team I · cross-border e-commerce transaction audit & fake-order risk detection**

> **Live demo (GitHub Pages):** <https://kaito-ayano.github.io/sentinel/>
> 双击 `index.html` 亦可在本地运行（数据走本地 `demo_data.js`，图表需联网加载 ECharts CDN）。

## What it is

A pure front-end demonstration of an **Agentic-AI audit workflow**: from an auditor's perspective, define risk rules first, connect shared resources into a graph to expose fraud rings, and hand the final judgement back to a human with a full audit trail.

> 从审计现场经验出发：单点 AI 工具不可信——先定义风险规则，再用共享资源图谱拼出刷单团伙，最后把裁决权交还人工并留痕。规则 → 图谱 → 人工复核，三段式主动审计。

## Features (four tabs)

| Tab | Description |
|---|---|
| **Risk overview** | KPI cards (orders, anomaly share, high-risk accounts, suspected rings) + 30-day anomaly trend |
| **Risk rules** | Five auditable rules (R1–R5) with live threshold sliders; re-computation under 1 s |
| **Fraud-ring graph** | ECharts force graph; nodes = accounts (circles) and shared IP / device / address (squares); click to highlight a ring |
| **Human review** | Triage per account (confirm / exclude / pending) + operator + note; persisted in `localStorage`; exportable as a CSV evidence log |

## Risk rules (default thresholds)

| ID | Rule | Default |
|---|---|---|
| R1 | Night-burst ordering (00:00–05:59 within any 7-day window) | ≥ 5 orders |
| R2 | Early-burst after registration | ≥ 3 orders in first 7 days |
| R3 | Shared IP / device | IP ≥ 5 accounts or device ≥ 3 |
| R4 | Delivery-address clustering | ≥ 5 accounts |
| R5 | Repeated amounts within 7 days **and** resource shared by ≥ 4 accounts | ≥ 8 occurrences |

Account risk score = R1×3 + R2–R5×2; score ≥ 4 marks a high-risk account. A fraud ring is a connected component over shared resources in which ≥ 2 accounts hit ≥ 2 rules.

## Verification (deterministic, seed = 42)

| Metric | Value |
|---|---|
| Orders / accounts | 14,891 / 1,571 |
| R1–R5 hits | 161 / 175 / 249 / 167 / 171 |
| High-risk accounts | 172 (171 match the planted ground truth — one false positive) |
| Fraud rings detected | 8 (exactly the 8 planted rings) |
| Anomaly order share | 12.2% |
| Graph size | 233 nodes, 513 edges |

## Data & ethics

All data in this repository is **synthetic**, generated by [`gen_synthetic_orders.py`](gen_synthetic_orders.py) (fixed seed, fully reproducible). **No real transactions and no personal data are used.** A ground-truth file (`gang_truth.csv`) is included solely to validate rule precision. Every page carries the footer “合成演示数据，非真实数据”. We treat demonstrable data governance — reproducible generation, stated assumptions, no real data in demos — as part of the audit deliverable itself.

## Run locally

Double-click `index.html`, or serve the folder: `python -m http.server 8000` → `http://localhost:8000/`.

## Stack

HTML + vanilla JavaScript + ECharts 5 (CDN) + Blob-based CSV export; no backend, no build step.

## Deploy to GitHub Pages

Repository **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**. The site is live in 1–2 minutes.
